# Retail Sales & Business Performance Analytics Using SQL

##  Project Overview

This project focuses on analyzing retail sales and business performance using MySQL. It involves designing a relational database, managing retail data, writing SQL queries, and generating meaningful business insights to support data-driven decision-making.

The project analyzes customer behavior, product performance, regional sales, employee performance, payments, and returns.

##  Tools & Technologies Used

- MySQL
- MySQL Workbench
- SQL
- Relational Database Management
- Data Analysis and Business Intelligence

##  Project Objectives

- Design and develop a relational retail database.
- Create and manage multiple tables using SQL.
- Insert and manage sample retail business data.
- Perform data retrieval using SQL queries.
- Analyze sales and profitability.
- Identify top-performing products and customers.
- Evaluate regional and monthly sales performance.
- Analyze cancelled orders and returned products.
- Generate business insights and recommendations.

##  Database Design

The project consists of 9 relational tables:

| Table Name | Description |
|---|---|
| customers | Stores customer information |
| products | Stores product details and pricing |
| categories | Stores product categories |
| regions | Stores regional information |
| employees | Stores employee details |
| orders | Stores customer order information |
| order_items | Stores individual products in each order |
| payments | Stores payment details and statuses |
| returns | Stores returned product information |
